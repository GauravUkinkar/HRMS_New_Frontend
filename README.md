# HRMS Project Work Guidelines

Please follow the instructions below before and during project development:

### 1. Read the Documentation

Read the project documentation thoroughly before starting any work. Make sure you understand the project requirements, workflow, and assigned tasks.

### 2. Create a CRM Entry

Before starting development, create a project entry in the CRM with all the required details.

### 3. Update the Google Sheet

Open the project Google Sheet and update your assigned task status before you begin working.

### 4. Keep the Status Updated

Update your task status in the Google Sheet regularly using the appropriate status:

- **Pending**
- **In Progress**
- **Completed**

### 5. Report Errors or Blockers

If you encounter any issues, errors, or blockers while working, update the **Comments** column in the Google Sheet with the issue and any relevant details.

### 6. Start Development

Once the CRM entry has been created and the Google Sheet has been updated, you may begin working on the actual project.

### 7. Update Before Stopping Work

If you stop working on the project for any reason (end of the day, task on hold, waiting for clarification, etc.), update the Google Sheet with the appropriate status (**Pending**, **In Progress**, or **Completed**) before leaving.

### 8. Mark Tasks as Completed

After finishing your assigned task, mark it as **Completed** in the Google Sheet and add any necessary comments or notes.

### 9. Follow the Assigned Task

Work only on the tasks assigned to you. If you need to work on a new task, ensure it is assigned and updated in both the CRM and the Google Sheet.

### 10. Maintain Daily Updates

Keep the CRM and Google Sheet up to date throughout the day so that the entire team can easily track project progress.
